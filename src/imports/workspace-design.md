Design the workspace system for the healthcare application.

The workspace must be role aware.

Roles include:
- Intake / Admissions Coordinator
- Scheduler / Care Coordinator
- Clinician
- QA Reviewer
- Billing / A/R Specialist
- Hospice Staff
- Medical Director
- Administrator

Each role must have a personalized operational workspace.

Workspace Layout Zones

ZONE 1: Critical Issues (Need Attention Now)
Display queue cards for:
- incomplete admissions
- delayed visits
- EVV errors
- missing signatures
- QA returns
- HOPE assessments due
- expiring authorizations

ZONE 2: Today's Work
- today's visits
- open shifts
- scheduled admissions
- clinician documentation due

ZONE 3: Resume Work
- recently opened patients
- recent admissions
- recent claims batches
- recent QA reviews

ZONE 4: Quick Actions
Buttons for:
- create patient
- create admission
- schedule visit
- post open shift
- upload patient document
- open EVV monitor
- start HOPE assessment

ZONE 5: Operational Insights
Lightweight metrics:
- visits today
- unresolved issues
- claims ready
- auth expiring
- hospice documents pending

The workspace must emphasize operational priorities rather than analytics dashboards.
