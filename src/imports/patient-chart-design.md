Design the Patient Chart for a modern healthcare platform supporting home health and hospice care.

The patient chart must allow users to quickly understand the patient’s current status and navigate clinical information efficiently.

Layout Structure

Sticky Patient Context Header

Always visible when viewing patient information.

Display:

Patient name
Date of birth / age
MRN or account number
Office
Admission status
Payer tags
Discipline tags
Alerts
Quick action buttons

Quick actions should include:

Schedule visit
Start documentation
Upload document
Send internal message

Admission Switcher

If the patient has multiple admissions, include a dropdown to switch the active admission.

Left Navigation Panel

Provide chart navigation:

Overview
Admissions
Visits
Clinical Documentation
Documents
Billing
Hospice
Activity

Main Content Area

Displays the selected section.

Overview Page

Display summary cards:

Active admissions
Care team members
Insurance information
Upcoming visits
Documentation due
Alerts

Visits Section

Show a table of visits including:

date
discipline
caregiver
status
documentation status

Clinical Documentation Section

Display visit notes, plans of care, and orders.

Documents Section

Show uploaded patient documents organized by folders.

Right Context Drawer

Provide additional contextual information including:

alerts
care team
authorization summary
recent activity
recent documents

The patient chart must allow users to access important information without navigating away from the current context.
