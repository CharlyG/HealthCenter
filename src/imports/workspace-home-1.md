Design the primary Workspace / Home screen for a healthcare operations platform used by home health and hospice agencies.

The workspace must function as an operational command center rather than a traditional dashboard.

The purpose of the workspace is to help users immediately understand:

• what needs attention right now
• what work is scheduled today
• what tasks are incomplete
• what operational issues exist

The workspace must adapt to user roles such as:

Admissions Coordinator
Scheduler / Care Coordinator
Clinician
QA Reviewer
Billing Specialist
Hospice Staff
Medical Director
Administrator

Layout Structure

Top Header
Display:

user name
office
quick search bar
notification icon
command palette shortcut

Zone 1 — Critical Issues (Highest Priority)

Display queue cards for items that require immediate attention.

Examples:

Admissions missing required fields
Delayed visits
EVV transmission failures
Missing physician signatures
QA returned documents
HOPE assessments due
Expiring authorizations

Each queue card must display:

count of items
short explanation
quick action button

Clicking the card should open the corresponding work queue.

Zone 2 — Today’s Work

Display panels showing:

Today's visits
Open shifts
Today's admissions
Upcoming patient visits

Zone 3 — Resume Work

Display lists for:

Recently opened patients
Recently edited admissions
Recent documentation activity
Recent billing actions

Zone 4 — Quick Actions

Provide large buttons for common actions:

Create Patient
Create Admission
Schedule Visit
Post Open Shift
Upload Patient Document
Start HOPE Assessment

Zone 5 — Operational Insights

Display lightweight summary cards:

Visits today
Open operational issues
Claims ready to submit
Authorizations expiring
Hospice signatures pending

Design Requirements

The workspace must prioritize operational awareness rather than analytics charts.

Use clear hierarchy and visual grouping to help users scan the screen quickly.

Avoid clutter and keep the interface calm and professional.
