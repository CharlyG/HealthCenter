# Physical Therapy Clinical Module

## Overview

Comprehensive clinical documentation module for physical therapists providing home health services. Supports all required PT documentation types with structured data collection, validation, and regulatory compliance.

## Document Types

### 1. PT Evaluation
Initial comprehensive assessment performed within 5 days of admission.

**Purpose:** Establish baseline functional status, identify limitations, set therapy goals, and create treatment plan.

**Sections:**
1. **Patient Condition** - Medical diagnosis, history, medications, prior function
2. **Functional Limitations** - ADLs, ambulation, transfers, stairs, bathing, dressing
3. **Pain Assessment** - Location, intensity (rest/activity), quality, aggravating factors
4. **Mobility Evaluation** - ROM measurements, MMT grading, balance, gait assessment
5. **Therapy Goals** - Short-term (2-4 weeks) and long-term (discharge) functional goals
6. **Treatment Plan** - Interventions, frequency, duration, skilled need justification

**Key Fields:**
- Referral diagnosis and date of onset
- Ambulation status and assistive device
- ROM measurements (goniometric)
- Muscle strength grading (0-5 MMT scale)
- Berg Balance Scale score
- Gait distance and pattern
- Timed Up and Go test
- Functional goals (SMART format)
- Treatment frequency and duration
- Skilled care justification

**Estimated Time:** 90 minutes  
**Required Frequency:** Once at admission

---

### 2. PT Visit Note
Documentation for routine treatment sessions.

**Purpose:** Document skilled interventions provided, patient response, and progress toward goals.

**Sections:**
1. **Visit Details** - Date, time in/out, visit number
2. **Interventions Performed** - Specific treatments provided this visit
3. **Patient Response** - Tolerance, vital signs, pain, participation level
4. **Progress Toward Goals** - Status of each functional goal
5. **Plan Updates** - Changes to treatment, next visit focus, coordination needs

**Key Fields:**
- Interventions: therapeutic exercise, gait training, balance, transfers, stairs, neuromuscular re-education, manual therapy, modalities, home exercise, education
- Activity tolerance (good/fair/poor)
- Vital signs response
- Pain level during treatment
- Patient participation level
- Goal progress status
- Plan modifications

**Estimated Time:** 30 minutes  
**Required Frequency:** Every visit

---

### 3. PT Progress Note
Periodic comprehensive reassessment of patient progress.

**Purpose:** Summarize progress over time period, reassess functional status, update goals and treatment plan.

**Sections:**
1. **Progress Summary** - Overall progress rating, visits completed
2. **Current Functional Status** - Objective measurements, functional abilities
3. **Goals Status** - Progress toward each short-term and long-term goal
4. **Treatment Plan Changes** - Frequency changes, treatment focus adjustments

**Key Fields:**
- Period start date
- Total visits completed
- Overall progress rating (excellent/good/fair/minimal/plateau/regression)
- Current ambulation status and gait distance
- Current balance and transfer status
- Current pain level
- Short-term goals status (achieved/progressing/slow/not met/revised)
- Long-term goals status
- New or revised goals
- Frequency change recommendations
- Continued skilled need justification
- Discharge planning considerations

**Estimated Time:** 45 minutes  
**Required Frequency:** Every 30 days (Medicare requirement)

---

### 4. PT Discharge Summary
Final documentation at end of PT services.

**Purpose:** Document outcomes, summarize episode, provide recommendations for post-discharge care.

**Sections:**
1. **Discharge Information** - Date, reason for discharge, total visits
2. **Status at Admission** - Baseline functional levels
3. **Status at Discharge** - Final functional levels
4. **Goals and Outcomes** - Achievement summary
5. **Recommendations** - Home program, DME, modifications, follow-up care

**Key Fields:**
- Discharge date and reason (goals met/plateau/declined/hospitalized/etc.)
- Total visits completed
- Admission ambulation, transfers, balance, pain
- Discharge ambulation, transfers, balance, pain
- Goals achievement (all/most/some/minimal/none met)
- Home exercise program provided
- DME recommendations
- Home modifications recommended
- Follow-up care recommendations
- Ongoing safety concerns
- Overall discharge summary

**Estimated Time:** 60 minutes  
**Required Frequency:** Once at discharge

## Clinical Features

### Range of Motion (ROM) Assessment
- Document active and passive ROM for affected joints
- Use goniometric measurements when possible
- Compare to normal values and baseline
- Track changes over time

**Common Joints:**
- Shoulder: Flexion (0-180°), Abduction (0-180°), External rotation (0-90°)
- Elbow: Flexion (0-150°)
- Hip: Flexion (0-120°), Abduction (0-45°), Extension (0-30°)
- Knee: Flexion (0-135°)
- Ankle: Dorsiflexion (0-20°), Plantarflexion (0-50°)

### Manual Muscle Testing (MMT)
Standardized 0-5 grading scale:
- **5 (Normal):** Full ROM against gravity with maximum resistance
- **4 (Good):** Full ROM against gravity with moderate resistance
- **3 (Fair):** Full ROM against gravity only
- **2 (Poor):** Full ROM with gravity eliminated
- **1 (Trace):** Muscle contraction palpable but no movement
- **0 (Zero):** No muscle contraction

### Balance Assessment
**Static Balance:** Standing balance without movement
**Dynamic Balance:** Balance during movement/transfers

**Standardized Tests:**
- **Berg Balance Scale:** 0-56 points
  - 0-20: High fall risk
  - 21-40: Medium fall risk
  - 41-56: Low fall risk
- **Single Leg Stance:** Seconds maintained
- **Functional Reach Test:** Distance in inches

### Gait Assessment
**Pattern Types:**
- Normal
- Antalgic (pain-related limp)
- Hemiplegic (stroke-related)
- Trendelenburg (hip weakness)
- Shuffling (Parkinson's)
- Ataxic (coordination impairment)

**Objective Measures:**
- **Gait Distance:** Maximum distance patient can ambulate
- **Gait Speed:** Normal, decreased, severely decreased
- **Timed Up and Go (TUG):**
  - <10 seconds: Normal
  - 10-20 seconds: Mild impairment
  - >20 seconds: High fall risk

### Functional Status Levels
Based on assist level required:
- **Independent:** No assistance needed
- **Modified Independent:** Uses device but no human assist
- **Supervised:** Requires observation for safety
- **Contact Guard Assist:** Hands-on for balance only
- **Minimal Assist (25%):** Performs 75% of task
- **Moderate Assist (50%):** Performs 50% of task
- **Maximal Assist (75%):** Performs 25% of task
- **Dependent:** Unable to assist

## Goal Setting

### SMART Goals Format
All therapy goals must be:
- **Specific:** Clearly defined functional outcome
- **Measurable:** Objective criteria for achievement
- **Achievable:** Realistic given patient condition
- **Relevant:** Meaningful to patient's life
- **Time-bound:** Target date for achievement

### Examples

**Short-Term Goal (2-4 weeks):**
> "Patient will ambulate 100 feet with rolling walker and supervision on level surfaces with no more than 2 rest breaks by 4/1/2026."

**Long-Term Goal (Discharge):**
> "Patient will ambulate 300 feet independently with cane on level surfaces and negotiate stairs with rail independently for safe discharge home by 5/1/2026."

## Regulatory Compliance

### Medicare Requirements

**Documentation Timing:**
- PT Evaluation within 5 days of admission
- Visit notes for every skilled visit
- Progress notes every 30 days minimum
- Discharge summary at discharge

**Skilled Need Justification:**
Every document must clearly explain why skilled PT services are necessary:
- Complexity requires PT expertise
- Patient/caregiver cannot safely perform independently
- Teaching complex techniques or exercises
- Ongoing assessment and adjustment needed
- Safety supervision required

**Functional Focus:**
Documentation must emphasize functional outcomes, not just impairments:
- ✓ "Patient improved from min assist to supervision for transfers"
- ✗ "Patient's quad strength improved from 3/5 to 4/5"

### Required Elements

**Every Document Must Include:**
- Patient identification
- Date of service
- Clinician name and credentials
- Skilled interventions provided
- Patient response
- Progress (or lack thereof)
- Plan for continued care
- Signature (electronic or wet)

**Evaluation Must Include:**
- Medical diagnosis and precautions
- Prior level of function
- Current functional limitations
- Objective measurements (ROM, strength, gait, balance)
- Safety assessment and fall risk
- Functional goals (ST and LT)
- Treatment plan with frequency/duration
- Rehabilitation potential
- Skilled need justification

- "Gait training with rolling walker on level surfaces with emphasis on heel-toe pattern and upright posture"

**Progress Statements:**

## Best Practices

### Documentation Tips

1. **Be Specific:** Use exact measurements, distances, assist levels
   - ✓ "Patient ambulated 75 feet with rolling walker and min assist"
   - ✗ "Patient ambulated short distance with walker"

2. **Use Objective Data:** Include measurable information
   - ✓ "Knee flexion ROM improved from 90° to 105°"
   - ✗ "ROM improved"

3. **Document Skilled Need:** Explain WHY PT is required
   - ✓ "PT skilled services needed for safety training with new assistive device and gait pattern modification to prevent falls"
   - ✗ "PT for gait training"

4. **Show Progress:** Compare to baseline and goals
   - ✓ "Patient improved from mod assist (baseline) to min assist for transfers, progressing toward goal of supervision"
   - ✗ "Patient requires min assist"

5. **Address Setbacks:** Explain lack of progress
   - ✓ "Patient experienced setback due to hospitalization for pneumonia; current plan focuses on regaining prior function"
   - ✗ "Patient not progressing"

### Common Pitfalls to Avoid

❌ **Vague Descriptions:** "Some improvement noted"  
✓ **Specific Statements:** "Gait distance increased from 50 feet to 100 feet"

❌ **Impairment Focus:** "Knee flexion is limited"  
✓ **Functional Focus:** "Limited knee flexion impairs stair climbing and car transfers"

❌ **Missing Skilled Need:** "Continue PT per plan"  
✓ **Clear Justification:** "Skilled PT needed for progression of strengthening program and modification of home exercise program based on ongoing assessment"

❌ **Copy-Paste Documentation:** Identical notes for every visit  
✓ **Individualized Notes:** Reflect actual activities and patient-specific responses

## Usage

### Access the Module

**Main Module:** `/physical-therapy-module`
- View all PT documents
- Create new documents by type
- Filter and search existing documents

**Demo Page:** `/physical-therapy-module-demo`
- Interactive demonstration
- Select document type
- View template structure
- Test documentation editor

### Create New Document

1. Navigate to PT Module
2. Click document type card (Evaluation, Visit Note, Progress Note, or Discharge)
3. Select patient and admission
4. Document auto-saves as you complete sections
5. Review validation panel before submission
6. Sign electronically when complete

### Best Workflow

**Initial Evaluation:**
1. Complete Patient Condition section during intake interview
2. Perform objective tests (ROM, MMT, balance, gait)
3. Document findings in Mobility Evaluation
4. Establish SMART goals based on findings
5. Create treatment plan with skilled need justification
6. Review for completeness and sign

**Routine Visit Note:**
1. Complete Visit Details (date, times)
2. Check off interventions performed
3. Document patient response and tolerance
4. Update goal progress
5. Note any plan changes
6. Sign immediately after visit

**Progress Note (every 30 days):**
1. Review all visits since last progress note
2. Perform reassessment of functional status
3. Update goal status (achieved/progressing/revised)
4. Justify continued skilled need
5. Recommend frequency changes if appropriate
6. Discuss discharge planning if goals nearly met

**Discharge Summary:**
1. Complete on date of last visit
2. Document reason for discharge
3. Compare admission vs discharge status
4. Summarize goal achievement
5. Provide home program and recommendations
6. Include any ongoing safety concerns

## Technical Architecture

### Components
- `/src/app/pages/PhysicalTherapyModule.tsx` - Main module interface
- `/src/app/pages/PhysicalTherapyModuleDemo.tsx` - Demo and documentation
- `/src/app/lib/physicalTherapyTemplates.ts` - Document templates
- `/src/app/lib/documentationTypes.ts` - Type definitions (shared)
- `/src/app/components/documentation/` - Reusable documentation components

### Templates
All PT templates use the standardized `DocumentTemplate` structure with sections and fields defined in `physicalTherapyTemplates.ts`.

### Data Flow
1. User selects document type
2. System loads appropriate template
3. Creates `ClinicalDocument` instance
4. `ClinicalDocumentationLayout` renders sections
5. User completes fields with validation
6. Document saves to backend via `dataGateway`
7. Status updates (in_progress → completed → signed)

### Common Questions

**Q: Can I save a partial document and finish later?**  
A: Yes, documents auto-save and can be resumed anytime. Look for "In Progress" status in document list.

**Q: What if I make a mistake after signing?**  
A: Contact your supervisor. Signed documents are locked but can be amended with addendum note following agency policy.

**Q: Do I need internet connection?**  
A: For best experience, yes. Offline mode is available but requires initial setup with IT department.

**Q: How do I document a missed visit?**  
A: Do not create visit note. Missed visits are tracked in scheduling module and reported separately.
